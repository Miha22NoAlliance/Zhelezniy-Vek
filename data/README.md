# Локальные данные WalkRoute

Положите сюда файл OpenStreetMap PBF с точным именем:

`planet_39.4596,52.532_39.7153,52.6457.osm.pbf`

Итоговый путь:

`data/planet_39.4596,52.532_39.7153,52.6457.osm.pbf`

После первого запуска рядом появятся автоматически созданные `lipetsk_graph.json` и `lipetsk_map.json`.
